# In This Town — audio rules

**Official theme (owner-approved 2026-11-28):** `music/in-this-town-theme.mp3`
(the first, original version: music box, soft keys, lo-fi crackle, 90 s).
A playable copy is `music/in-this-town-theme.mp4`.

Use this track as the background music in every "In This Town" video and Short.

- Mix it under the narration at about 15–20 % volume (around -18 to -22 dB below the voice) so the voice stays clear.
- Start it at 0:00. If the video runs longer than 90 s, loop it with a short crossfade.
- Fade it out over the last 1–2 s.

The other tracks in `music/` (hard, fun, ten-ten-ten) are alternatives only. Don't use them unless the owner asks.
