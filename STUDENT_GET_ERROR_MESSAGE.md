# For Student: Get the Actual Error Message

## Quick Instructions (2 minutes)

### Step 1: Open Browser Developer Tools
Press **F12** on your keyboard

### Step 2: Go to Console Tab
Click the **Console** tab (you might need to click the dropdown if it shows "Elements")

### Step 3: Clear Console (Optional but helpful)
Right-click → "Clear console" (to remove old messages)

### Step 4: Try Submitting
1. Fill in both parts of the writing test
2. Click the Submit button

### Step 5: Look for Error Messages
In the console, you should see **red text** that starts with one of these:

```
❌ Failed to submit:
HTTP xxx:
💥 Critical error:
[Error]:
```

### Step 6: Copy the Error
Select all the red text and copy it (Ctrl+C)

### Step 7: Send to Teacher
Share the error message with your teacher

---

## What the Error Might Say

### Example 1: Permission Error
```
❌ Failed to submit: HTTP 403 permission denied
💥 Critical error: Permission denied
```
→ Tell teacher: "I'm getting HTTP 403 permission denied error"

### Example 2: Network Error  
```
❌ Failed to submit: Network error. Check your internet connection.
Failed to fetch
```
→ Tell teacher: "I'm getting a network error"

### Example 3: Auth Error
```
❌ Failed to submit: HTTP 401 Unauthorized
Unauthorized
```
→ Tell teacher: "I'm getting HTTP 401 Unauthorized"

### Example 4: Server Error
```
❌ Failed to submit: HTTP 500 Internal Server Error
```
→ Tell teacher: "I'm getting HTTP 500 server error"

---

## If You Don't See Any Red Error

1. Scroll up in the console
2. Look for any messages with red text or ❌
3. Look for messages with emojis like 📤 or 💥
4. Look for anything that says "Error" or "error"

If you genuinely see nothing red, take a screenshot and send it to your teacher.

---

## Quick Troubleshooting

**Q: I closed the console and it's gone, how do I see the error again?**
A: Do the same steps above - clear console, then try submitting again

**Q: I see lots of messages, which one do I copy?**
A: Look for the one that starts with ❌ or 💥 - copy from there until you see the next message

**Q: The error is really long, do I copy all of it?**
A: Yes, copy the entire error message (even if it's long)

---

## Send This to Teacher

When you send the error, include:
1. The exact error message from the console
2. The date and time you tried
3. Your student name and class
4. Whether it's the first time submitting or a retake

Example:
```
Teacher, I'm getting this error when I try to submit Cambridge Writing Test 2:

❌ Failed to submit: HTTP 403 permission denied
💥 Critical error: Permission denied

I tried at 2:30 PM on January 14, 2026.
My name is [name] and I'm in [class].
This is my first attempt.
```

---

That's it! Your teacher will use this error to fix the problem.
