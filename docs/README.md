# Brains Heist Documentation Hub

Welcome to the documentation bundle for **Brains Heist** – a light-mode, spy/heist themed adaptive learning platform built with Supabase, Next.js, TypeScript, and Tailwind. These pages are designed to onboard developers, teachers, and student agents quickly.

| Developers | [Database Schema Reference](./database.md) | Tables, relationships, triggers |

| Teachers (Handlers) | [Teacher Mission Builder Guide](./teacher-guide.md) | Creating subjects, topics, missions, analytics |

| Content Editors | [Biology Question Import Workflow](./BIOLOGY_QUESTION_IMPORT_WORKFLOW.md) | Chapter-based import from image PDFs with max 30 questions per test part |
| Data Owners & Operations | [Data, Business Logic & Functionality Guide](./DATA_BUSINESS_LOGIC_FUNCTIONALITY_GUIDE.md) | Domain ownership, rule integrity, KPI and stewardship routines |
