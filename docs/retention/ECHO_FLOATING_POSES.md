# Echo floating companion and poses

Extends the named Gulzada/Jess pilot. No new database migration, RPC, realtime subscription, dependency, scoring/reward change or wider audience. The existing teacher appreciation and encouragement keepsakes remain intact.

Six consistent character poses: original greeting plus curious, thinking, celebration, crew cheer and teacher keepsake. Five transparent variants were generated with the built-in image-generation tool, using `public/retention/heist-companion-v1.webp` as the strict identity reference. Full-body pose/expression changes retain graphite armor, cyan LED face and ears, pink scarf, cyan key badge, purple trim and mechanical fox tail. Variants are individually compressed WebPs (28,650–32,602 bytes each), requested only when needed on a visible surface. No blanket pose preloading. Failed or stale downloads return to the original greeting and cannot replace a newer response; the original image has a code-native SVG fallback.

Original SVG energy paths are aligned separately to each pose and alpha-masked to its body. The saved cyan/pink/violet aura colours visible strands on the ears, tail and coat, preserving the original artwork. Mask URLs use the same already-requested pose asset. Strand flow is finite; pose arrivals are short. Reduced-motion users get a still greeting and skip extra pose downloads.

The larger companion card remains the place to name/personalise Echo, read stories and keep teacher encouragement. An optional `Let Echo float` toggle adds a small portal surface outside the card. It starts off by default, can be dragged by its grip, docks to the nearest horizontal edge, supports arrow keys (Shift moves farther) and Home/End edge positioning. Pointer movement stays local; device preferences are written only on completed drag, keyboard movement or explicit mode/tuck controls. Saved floating position, enabled state and tuck state are account-scoped on that device. The companion's name/aura retain the existing cross-device server persistence.

Tuck collapses Echo into a small restore chip; the close button turns floating mode off. There is always a card toggle to disable it. Position bounds reserve 100 pixels at the bottom for navigation, and re-clamp on resize. Free positioning can overlap dashboard content, so the float is small, opt-in and immediately movable/tuckable. Native practice dialogs remove the floating surface entirely; closing restores it. A successful saved round returns Echo in the celebration pose. Greetings, clues, shared cheers and keepsakes trigger appropriate expressions, with a six-expression preview in the card. Existing sound remains user-controlled; no idle sound is added.

Optional gentle CSS bob runs only for a visible floating avatar, with a transform animation. IntersectionObserver, page visibility, reduced motion and drag state pause it. There is no WebGL or continuous JavaScript rendering loop. Effects, observer, activity listener, media listener and pose timer clean up on unmount; hiding/pausing the trial removes the portal as well.

Validation: focused TypeScript; 46 retention/DOM/database/model/audio checks including drag clamp/dock/persistence, keyboard positioning, tuck/restore/disable, account-scoped preferences, dialog hiding/restoration, visible-only pose requests, late-load races, download fallback, reduced motion and observer cleanup. All six original pose assets were visually inspected, and actual alpha-masked cyan/pink/violet strand composites were rendered and inspected. Full CI must pass at exact head before merge. Signed-in Safari/iPhone touch, masking and visual/layout acceptance remain pilot checks; no concurrency benchmark or zero-risk promise.

Cancellation: turn floating mode off or tuck it away; use existing Hide trial / owner Pause trial everywhere for the entire pilot. No data deletion is required.

Asset prompts: strict identity-reference edit; one transparent full-body 3D-style cyber-fox, same costume/material/lighting, centered square framing, no text or background. Pose instructions: curious head tilt/hand to chin; cross-legged thoughtful float; happy arms-up jump; supportive thumbs-up; holding a blank heart envelope as a teacher keepsake. Source images remain unmodified; WebP conversion is project asset optimisation.
