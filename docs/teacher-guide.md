# Brain Heist Teacher Quick Start

This guide is for teachers using the Brain Heist web app. You should never need to open Supabase, edit database tables, or know student UUIDs.

## Before you begin

Your school admin completes the school-level setup:

- activates the school plan;
- adds teachers and students;
- creates classes and subjects;
- assigns each teacher to the correct class and subject.

If the Teacher Portal says **No classes assigned**, contact your school admin. Creating content will not fix missing class access.

## Your first assignment

1. Sign in at [brainsheist.com](https://www.brainsheist.com/).
2. Open the **Teacher Portal**.
3. Check **Teacher Quick Start** on the dashboard.
4. Confirm that your class and subject are listed.
5. Open **Question Bank**.
6. Select approved questions, or create your own question if your school permits it.
7. Open **Assignments** and choose **New Assignment**.
8. Add a clear title, select the class and subject, choose the questions, and set the deadline.
9. Review the summary, then publish the assignment.
10. Return to **Dashboard** or **Reports** to follow completion.

## What each area is for

| Area | Use it for |
| --- | --- |
| Dashboard | Your setup status, current priorities, recent work, and class health |
| Question Bank | Browse approved content and create or manage your own questions |
| Assignments | Create work and check assignment status |
| Reports | Review completion, scores, and student-level results |
| Writing Monitor | Track student writing progress and support needs |
| Writing Analytics | Find class patterns and weak writing skills |
| Writing Reports | Prepare and export writing report cards |
| Lockdown Mode | Run a controlled live classroom session |
| Cambridge Tests | Review test results and mark teacher-assessed work |
| Quest Builder | Turn your own questions into a playable mission |

## Common first-login states

### No classes assigned

Your school account is active, but the school admin has not assigned your class and subject yet. Ask the school admin to open **School Admin → Teachers** and complete the assignment.

### A feature is locked

Check the plan banner at the top of the Teacher Portal. If the pilot expired or the school has no active paid plan, ask the school admin to open **School Admin → Plan & Billing**.

### No students appear

The school admin must place students in your assigned class. Ask them to check **School Admin → Roster**.

### No questions appear

Refresh once. If the Question Bank is still empty, create a question if allowed or ask the school admin to confirm that approved content is available for your subject.

### Students cannot see an assignment

Confirm that the assignment is published, targets the correct class, and has not passed its closing date. Then ask the school admin to confirm the student is still enrolled in that class.

### Results are empty

Results appear after students submit work. Open the assignment to check its completion count before using Reports.

## A simple weekly routine

1. Review dashboard priorities.
2. Check unfinished assignments.
3. Review weak questions or students needing support.
4. Create the next focused assignment.
5. Mark teacher-assessed submissions.
6. Export or share reports when needed.

## Getting help

Use **Guide & Help** inside the Teacher Portal. For account, plan, or school-assignment issues, contact your school admin first. For product support, email [support@brainsheist.com](mailto:support@brainsheist.com).
