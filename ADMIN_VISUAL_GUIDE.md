## ✨ Animation Effects

### Spinning Crown 👑
- Rotation: 20 seconds per full spin
- Smooth, continuous motion
- Visible on admin button

### Pulsing Glow
- Opacity: 0.3 → 0.6 → 0.3
- Duration: 4 seconds
- Applies to borders and backgrounds

### Floating Particles
- 4 particles moving in figure-8 pattern
- Colors: Gold, Pink, Purple
- 20 second animation loop

### Hover Effects
- Light sweep across buttons
- Scale increase to 105%
- Shadow glow intensifies

## 🚀 What Happens When You Click Things

### Click "ADMIN" Button
→ Screen transitions to Admin Portal
→ Particles animate in
→ Header glows and floats
→ Dashboard tab is active by default

### Click "👻 GHOST MODE"
→ Button changes to "👁️ VISIBLE MODE"
→ Toast notification: "Admin now VISIBLE..."
→ You appear in leaderboards with golden styling
→ Database updates: admin_visible = true

### Click "💰 +1000" on a User
→ User's coins increase by 1000
→ Toast: "✨ Granted 1000 coins to [username]"
→ User list refreshes
→ User sees coins in their profile

### Click "⚡ Reset AP" on a User
→ User's AP resets to 20/20
→ Toast: "⚡ AP reset to 20"
→ User sees full AP bar immediately

## 📱 Responsive Design

All admin UI is responsive:
- Mobile: Single column layouts
- Tablet: 2-column grid for stats
- Desktop: Full 3-column layout
- Animations work on all devices
- Touch-friendly buttons
